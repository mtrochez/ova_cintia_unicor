# OVA Psicología organizacional y bienestar humano - Unidad 2: Cultura, Clima y Bienestar Organizacional

## Descripción General

Objeto Virtual de Aprendizaje para la **Especialización en Gerencia del Talento Humano y Desarrollo Organizacional** de la Universidad de Córdoba, enfocado en el análisis de la cultura organizacional, el clima laboral y el bienestar humano.

El OVA integra tres actividades prácticas: un simulador OCAI para identificar perfiles culturales, un laboratorio de dashboards para relacionar indicadores de clima y resultados financieros, y un taller de ritualización para diseñar prácticas de integración inclusivas en equipos multiculturales e híbridos.

---

## Objetivos de Aprendizaje

- Analizar la cultura organizacional mediante el modelo OCAI.
- Identificar oportunidades de transición cultural hacia prácticas de mayor innovación, colaboración y bienestar.
- Relacionar indicadores de clima laboral con resultados financieros a partir de datos trimestrales.
- Utilizar datos en formato CSV para crear visualizaciones en Power BI Desktop o Tableau Public.
- Diseñar rituales de integración inclusivos para equipos multiculturales y en modalidades de trabajo híbridas.

---

## Características Principales

### Actividad 1: Simulador OCAI

- Cuestionario guiado por dimensiones del modelo OCAI.
- Registro de organización y sector de referencia.
- Navegación paso a paso con barra de progreso.
- Perfil cultural resultante y transición orientada a una cultura de adhocracia.
- Prompt para consultar herramientas de inteligencia artificial.
- Espacio para redactar el plan de transición cultural.
- Exportación del resultado a texto (`.txt`) o Word (`.doc`).
- Botón de limpieza para reiniciar la actividad.

### Actividad 2: Laboratorio de Dashboards

- Caso de estudio editable para analizar relaciones entre clima laboral y resultados financieros.
- Dashboard interactivo por trimestres.
- Indicadores de satisfacción, compromiso, ausentismo, rotación, productividad, ingresos, margen operativo y costo por rotación.
- Tabla editable para personalizar los datos trimestrales.
- Descarga de datos en formato CSV para abrir en Power BI Desktop o Tableau Public.
- Guía de importación de datos para ambas herramientas.
- Caso sugerido: **Clínica del Caribe**, personalizable por el estudiante.

### Actividad 3: Taller de Ritualización

- Diseñador de ritual de integración para equipos multiculturales.
- Configuración de nombre del equipo, contexto de trabajo, propósito, frecuencia, participantes e indicador de seguimiento.
- Selección de momentos del ritual: apertura de conexión, voces del equipo, reconocimiento entre pares y cierre con compromiso.
- Recomendaciones de inclusión para equipos híbridos.
- Generación dinámica de una ficha de diseño.
- Exportación de la ficha del ritual a texto (`.txt`).
- Botón para restaurar el caso ejemplo.

## Cómo Usar

1. Abrir el archivo `index.html` en un navegador compatible.
2. Seleccionar una actividad desde el menú de actividades.
3. Completar cada actividad según sus instrucciones.
4. En la Actividad 1, responder el simulador OCAI, revisar el perfil y exportar el plan si se requiere.
5. En la Actividad 2, personalizar el caso y los datos trimestrales; descargar el CSV para usarlo en Power BI Desktop o Tableau Public.
6. En la Actividad 3, definir las características del equipo, seleccionar los momentos del ritual y exportar la ficha resultante.

## Requisitos Técnicos

### Navegadores Compatibles

- Chrome 80+.
- Firefox 75+.
- Safari 13+.
- Edge 80+.

### Tecnologías Utilizadas

- **HTML5**: estructura semántica del OVA.
- **Tailwind CSS (CDN)**: diseño responsivo y componentes visuales.
- **CSS3**: estilos personalizados, variables de color, sombras y transiciones.
- **JavaScript Vanilla**: simuladores, edición dinámica de datos y exportación de archivos.
- **Font Awesome 6**: iconografía.
- **Google Fonts (Poppins)**: tipografía.

### Integración con Herramientas de Visualización

El OVA no requiere una cuenta ni un enlace público de Power BI o Tableau. La Actividad 2 genera un archivo CSV que el estudiante puede importar manualmente en:

- **Power BI Desktop** mediante `Obtener datos > Texto/CSV`.
- **Tableau Public** mediante `Conectar > Archivo de texto`.

## Impacto Educativo

### Beneficios

- Facilita la aplicación del modelo OCAI en contextos organizacionales reales o simulados.
- Promueve el análisis responsable de datos de clima laboral y desempeño financiero.
- Acerca al estudiante a herramientas de visualización usadas en la gestión del talento.
- Favorece el diseño de prácticas inclusivas para fortalecer la cohesión de equipos diversos.
- Permite conservar productos académicos mediante exportaciones de texto, Word y CSV.

### Resultados Esperados

- Identificación del perfil cultural de una organización y de oportunidades de transformación.
- Formulación de hipótesis sobre la relación entre bienestar, clima laboral y resultados organizacionales.
- Creación de visualizaciones básicas en Power BI Desktop o Tableau Public a partir de datos exportados.
- Diseño de un ritual de integración aplicable a un equipo multicultural e híbrido.
